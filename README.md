# Wine Review Analysis for Product Selection

ワインレビューデータ分析に基づく商品選定

## Overview

データラーニングスクールの講座受講中に作成した、
ワインレビューデータを用いた商品選定の分析課題である。

スーパーマーケットでワインイベントを開催する想定で、
レビューデータを分析し、
仕入れ対象となるワイン10銘柄を選定した。

本課題では、SQLやPythonを用いた分析に進む前段階として、
Microsoft Excelを使用し、

- 課題設定
- 分析条件の設定
- データの抽出・集計
- 基本統計量の確認
- 可視化
- 結果の解釈
- 意思決定
- 分析結果の報告

までの一連の分析プロセスを経験した。

分析結果はPowerPointにまとめ、
グループメンタリングで報告した。

## Business Problem

スーパーマーケットの仕入れ担当者として、
ワインイベントを開催することを想定した。

ワインレビューデータを分析し、
イベントで販売する10銘柄を選定することを目的とした。

店舗条件は以下のとおりである。

- 郊外にある中型規模のスーパーマーケット
- イベント用の特設コーナーを設置可能
- 流通コストは考慮しない
- 一般的なワインも通常どおり販売する


## Event Concept

イベントのテーマには
**デザートワイン**を選択した。

ワインを日常的に飲まない層も含めた
機会飲酒層の取り込みを想定し、
市場動向や商品の特徴を踏まえて分析対象を設定した。


## Dataset

データラーニングスクールから提供された、
約13万件のワインレビューデータを使用した。

主に以下の情報を分析に利用した。

- ワインの商品情報
- 生産国・産地
- 価格
- 評価点
- テイスター情報
- レビュー文章
- 品種・ワイナリー情報

元データは講座提供物のため、
本リポジトリには掲載していない。

- テイスター別の集計

## Analysis Process

分析は以下の流れで行った。

1. イベントテーマの設定
2. デザートワインの分類
3. 販売価格帯の設定
4. テイスターの評価傾向の確認
5. 候補ワインの抽出
6. カテゴリーごとの比較
7. レビュー文章による最終候補の比較
8. 10銘柄の選定


## 1. Dessert Wine Classification

デザートワインを以下の5カテゴリーに分類した。

| Category |
| --- |
| 貴腐ワイン |
| アイスワイン |
| レイトハーヴェスト |
| モスカート・ダスティ |
| その他 |

産地、収穫方法、商品情報、
レビュー文章などを組み合わせて分類した。

講座提供データの具体的な項目名や
詳細な抽出条件は公開していない。


## 2. Price Range

外部のワイン購入価格に関する調査を参考に、
価格帯を

**15–30 USD**

に設定した。

分析時の換算レートは、

**1 USD = 100 JPY**

とした。

また、同一カテゴリー内で
同価格の商品が重複しすぎないよう考慮した。


## 3. Taster Selection

レビュー件数や評価傾向を確認し、
分析対象とするテイスターを絞り込んだ。

テイスターごとの

- 平均評価点
- 平均価格
- 評価傾向

を比較し、
価格と評価点の関係を検討した。

当時の分析では、
価格による評価への影響が大きい可能性があると判断した
一部のテイスターを選定対象から除外した。


## 4. Wine Selection

以下の条件を組み合わせて候補を絞り込んだ。

1. デザートワインに分類される
2. 設定した価格帯に該当する
3. 分析対象としたテイスターによるレビューである
4. カテゴリーごとに評価点の高い商品を優先する

単純に評価点の高い10銘柄を選ぶのではなく、
カテゴリー、価格、テイスターの評価傾向を考慮して
商品を選定した。


## 5. Review Text Comparison

数値条件だけでは候補を一つに絞れない場合に、
レビュー文章を比較した。

レビューに含まれる味覚表現をChatGPTで評価し、
より甘いと推測されるワインを選定した。

Excelによる定量的な絞り込みと、
ChatGPTによる自然言語の評価を組み合わせた点が
本分析の特徴である。

**10銘柄のデザートワイン**を選定した。

## Retrospective

本分析では、
Excelによる定量的な分析と
ChatGPTによるレビュー文章の評価を組み合わせた。

現在の視点では、以下の点を改善できると考える。

### テイスターの評価傾向

当時は平均価格と平均評価点を比較して
テイスターを絞り込んだ。

現在であれば相関分析なども利用し、
価格と評価点の関係をより客観的に検証する。

### ChatGPTによるレビュー文章の評価

当時はレビュー文章をChatGPTで比較し、
味覚表現から候補を選定した。

現在であれば評価基準やプロンプトを明確にし、
同じ条件で比較できるようにすることで
再現性を高める。

## Limitations

本分析は講座内の演習であり、
実際の商品仕入れを目的としたものではない。

主な前提・制約は以下のとおりである。

- 流通コストを考慮していない
- 為替レートを 1 USD = 100 JPY として固定している
- 現在の販売価格や在庫状況を考慮していない
- テイスターごとの評価傾向を完全には補正していない
- 国籍、産地、ワイナリーなどによる評価への影響は検証していない
- ChatGPTによるレビュー文章の評価は補助的な判断である
